# 12-Month Roadmap
## Phase 1 (Months 1-3) - Intelligence depth
- pgvector semantic retrieval; hybrid search.
- Real provider adapters (hosted + Ollama local bundle).
- Grading-aware explanation levels.
## Phase 2 (Months 4-6) - Access and language
- Progressive Web App with offline cached resources.
- Swahili interface and explanation support.
- Automated retention schedules and backup tooling.
## Phase 3 (Months 7-9) - Pilots
- Guided pilots in 3 schools, including one low-connectivity institution.
- Teacher feedback loop; curriculum packs (CBC/CBE, Cambridge).
- Community governance council formation.
## Phase 4 (Months 10-12) - Scale
- County-level deployment playbook; Docker hardening.
- Public model cards and impact report.
