# JIFUNZE AI - 3-Minute Demo Script
Audience: fellowship reviewers, school administrators, contributors.
Recording: Windows Game Bar (Win+G) or OBS; browser at 127.0.0.1:8000; zoom 110%.
## Setup (before recording)
1. .\jifunze runserver
2. Log in as School Administrator.
3. Prepare a small folder: Biology/Form 2/photosynthesis.txt (2-3 paragraphs).
## Act 1 - Sovereign upload (0:00-0:45)
Say: "A teacher gives JIFUNZE the school's own materials - in bulk, folder by folder."
Click: Upload Resource -> Select Entire Folder -> choose Biology -> Upload & Process All.
Show: progress bar, results table with topic "Biology > Form 2" and chunk counts.
## Act 2 - Grounded learning (0:45-1:40)
Say: "A learner's question is answered from the school's own resources - with citations."
Click: Learning Companion -> new conversation -> "What is the role of chlorophyll in photosynthesis?"
Show: assistant bubble plus the Sources line naming the uploaded document.
## Act 3 - Teacher time back (1:40-2:20)
Say: "The same material becomes a lesson plan and a quiz in seconds - curriculum-aware."
Click: Teacher Studio -> Lesson Plan -> topic Photosynthesis -> Form 2 -> CBC/CBE -> Generate.
Show: generated plan; then switch type to Quiz and generate again.
## Act 4 - Sovereignty in action (2:20-3:00)
Say: "Every action was audited. The school can export or delete its data at any time."
Click: Data Sovereignty Centre.
Show: audit rows RESOURCE_BULK_UPLOAD, AI_LEARNING_QUERY, TEACHER_ARTIFACT_GENERATED with provider metadata.
Click: Download my data (JSON) -> file downloads.
Click: submit deletion request -> Complete (as admin) -> conversations disappear; audit shows DATA_REQUEST_COMPLETED with deletion count.
Close: "Intelligence for everyone. Knowledge without boundaries."
